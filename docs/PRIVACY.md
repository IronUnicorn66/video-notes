# 本地数据与权限

## 数据流

视频笔记把笔记正文、截图、字幕片段、录音、转写结果和视频会话信息保存到扩展自己的 IndexedDB。模型权重保存在 Cache Storage。音频、字幕、截图和笔记不会上传到服务端。

首次下载本地语音模型时，插件会向 Hugging Face 的 `ggerganov/whisper.cpp` 固定 revision `98aa99a0a9db05ae2342309f5096248665f7cba3` 请求静态权重。可下载的模型为 Base · 57 MiB（59,707,625 字节）、Small · 181 MiB（190,085,487 字节）和 Medium · 514 MiB（539,212,467 字节）。Base 用于日常本地转写，Small 和 Medium 用于需要更大模型的场景；Medium 的下载、加载和转写会显著增加内存占用及耗时。下载完成并通过对应固定 SHA-256 校验后，插件撤销模型站点权限。后续转写可离线运行。

上传范围不包含录音、转写文本、字幕、截图或笔记正文。远程下载内容仅限静态模型权重；JavaScript、Worker 和 WASM 均由扩展安装包提供。

## 权限用途

- `storage`：保存快捷键、Whisper 状态和一次性联动提示状态。
- `activeTab`、站点权限：读取当前 YouTube/哔哩哔哩视频状态。
- 可选 `<all_urls>` 权限：Edge 的可见页面截图接口需要此权限或一次临时 `activeTab` 授权。用户在侧栏单独启用后，插件只会在受支持的 YouTube 和哔哩哔哩视频页截取当前可见播放器。
- `scripting`：为受支持页面建立内容脚本连接。
- `sidePanel`：提供持续可见的笔记输入和时间线。
- `offscreen`：在用户已从独立扩展页授权麦克风后，由隐藏扩展页面持续录音、运行本地 WASM/Worker、生成下载 Blob。
- `downloads`：保存用户主动导出的 ZIP。
- 可选模型主机权限：只用于用户主动发起的模型下载，缓存成功后撤销。

## 网课声伴协作

扩展间协议只发送协议版本、租约 ID、目标标签页 ID、超时时限和恢复资格。协议不会发送网址、标题、笔记、字幕、截图或录音。网课声伴只接受固定视频笔记扩展 ID，且目标标签页必须是当前 A 网课页。

## 删除数据

卸载扩展会由浏览器清除扩展存储。当前版本会保留所有已下载模型和已导出会话，导出动作不会删除本地记录。没有单模型删除入口；需要统一释放空间时，请在 Edge 扩展管理页清除本扩展数据。
