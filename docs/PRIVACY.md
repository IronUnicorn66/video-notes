# 视频笔记本地数据与权限说明

生效日期：2026 年 7 月 28 日

公开隐私政策：https://ironunicorn66.github.io/video-notes/privacy/

## 概述

视频笔记用于在 YouTube 和哔哩哔哩课程中记录带时点的个人笔记，并按用户选择附带播放器截图、已经渲染的字幕、原始录音和本地语音转写。本政策说明扩展处理的信息、用途、权限、存储和删除方式。

## 处理的信息

- 当前视频地址、标题、站点、视频标识、分 P 和播放时点。
- 用户输入的笔记正文、字幕修订和撤销/反撤销历史。
- 当前页面已经渲染的原生字幕或沉浸式翻译双语字幕。
- 用户主动启用截图后截取的可见播放器画面。
- 用户按住说话期间的麦克风录音与本地 Whisper 转写结果。
- 快捷键、字幕时长、时间线顺序、权限和模型状态设置。

扩展不会在后台建立浏览历史，也不会读取受支持视频页以外的网站内容来生成笔记。

## 存储与处理位置

笔记、字幕、截图、录音、转写结果和视频会话信息保存在扩展自己的 IndexedDB。设置保存在扩展存储中，模型权重保存在 Cache Storage。这些个人内容都在用户设备本地处理。

扩展没有开发者服务器，不会把笔记、字幕、截图、录音、转写结果或视频访问记录上传给开发者。扩展不包含账户、广告或分析统计，也不会出售、出租或共享用户数据。

## Whisper 模型下载

用户主动选择本地语音模型后，扩展会从 Hugging Face 的 `ggerganov/whisper.cpp` 固定 revision `98aa99a0a9db05ae2342309f5096248665f7cba3` 下载 Base、Small 或 Medium 静态权重。下载后会校验固定文件大小和 SHA-256，校验通过才会写入本地缓存。下载完成后，扩展撤销模型主机权限。

远程响应只包含静态模型数据。JavaScript、Worker 和 WASM 均由扩展安装包提供，转写在本机运行。

模型下载请求会直接连接 Hugging Face、其 CDN 或 XetHub。和普通 HTTPS 请求一样，这些服务会收到完成下载所需的连接元数据，例如 IP 地址、User-Agent、请求时间和模型文件地址；请求不会包含笔记、字幕、截图、录音或转写内容。扩展和开发者不读取或保存这些连接元数据。第三方如何处理连接元数据请参阅 [Hugging Face 隐私政策](https://huggingface.co/privacy)。

## 权限用途

- `storage`：保存设置、权限和模型状态。
- `activeTab`：在用户操作当前课程页时读取时点并请求可见页面截图。
- `scripting`：在受支持视频页连接失败时注入扩展包内的本地内容脚本。
- `sidePanel`：提供笔记输入、设置和时间线。
- `offscreen`：在授权后维持录音、本地转写和导出 Blob。
- `downloads`：保存用户主动导出的 ZIP。
- YouTube 与哔哩哔哩主机权限：读取播放器状态、时点和已经渲染的字幕。
- 可选 `<all_urls>`：只在用户启用播放器截图并同意 Edge 提示后授予；实际截图仍限定在受支持的视频页。
- 可选模型主机权限：只用于用户主动发起的固定 Whisper 权重下载，缓存完成后撤销。

## 麦克风与截图

麦克风只在用户按住右 Option/Alt 或侧栏“按住说话”按钮期间录音。窗口失焦、页面隐藏、侧栏关闭或达到 60 秒上限时会停止录音。

播放器截图默认关闭。用户必须在侧栏中单独启用并接受 Edge 的可选权限提示。关闭权限后，新笔记不再保存截图。

## 保留与删除

扩展会保留视频会话和已下载模型，便于再次打开同一视频时继续记录。用户可以删除单条笔记、清空当前视频会话或在 Edge 扩展管理页清除本扩展数据。卸载扩展会由浏览器清除扩展存储。

导出 ZIP 不会删除浏览器中的会话。已经保存到下载目录的 ZIP 由用户自行管理。

## 政策更新

如果扩展的数据处理方式、权限或联网范围发生变化，本页面会在新版本发布前更新，并修改顶部生效日期。
