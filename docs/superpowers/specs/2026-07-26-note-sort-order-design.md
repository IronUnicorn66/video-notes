# 侧栏笔记排序设计

## 目标

在视频笔记侧栏的“标记时间线”中提供“最新在前”和“最早在前”两种显示顺序。首次使用默认“最新在前”，并在所有视频间记住用户最后一次选择。

## 范围

- 只调整侧栏时间线的显示顺序。
- ZIP 和 Markdown 继续按时间正序导出。
- IndexedDB 中的会话、笔记和资产结构保持不变。
- 不增加逐视频排序偏好、自动滚动设置或其他时间线筛选功能。

## 交互

- 在“标记时间线”标题与“导出 ZIP”按钮之间增加排序下拉框。
- 下拉框提供“最新在前”和“最早在前”两个选项。
- 插件没有保存过偏好时选择“最新在前”。
- 用户切换选项后，当前时间线立即重新排列，无需刷新视频页或侧栏。
- “最新在前”模式保存新笔记后，新笔记出现在列表顶部；“最早在前”模式下出现在列表底部。
- 空时间线仍显示原有空状态，排序选项保持可操作。

## 状态与数据流

- 使用 `chrome.storage.local` 保存全局偏好，键名为 `noteSortOrder`。
- 合法值限定为 `newest` 和 `oldest`；缺失或未知值统一回退到 `newest`。
- 侧栏初始化时先读取偏好，再进行首次笔记渲染，避免先显示正序后跳成倒序。
- 侧栏保留当前会话最近一次取得的笔记数组。切换排序时只重新渲染该数组并保存偏好，不重新请求后台。
- 排序函数复制输入数组后再排序，避免改变仓库返回值和其他消费者看到的顺序。
- IndexedDB 的 `listNotes()` 继续返回时间正序，导出流程不读取侧栏偏好。

## 代码边界

- 新增独立的侧栏排序核心模块，负责规范化偏好值和生成显示顺序。
- `sidepanel.html` 只增加排序控件。
- `sidepanel.css` 只增加时间线操作区和紧凑下拉框样式。
- `sidepanel.js` 负责初始化偏好、缓存当前笔记、响应选择变化并调用排序模块。
- 后台脚本、存储仓库和导出模块不修改。

## 异常处理

- 读取偏好失败时使用“最新在前”，侧栏其他功能继续运行。
- 保存偏好失败时保留本次页面内选择，并显示现有 toast 提示；关闭侧栏后可能恢复上次成功保存的值。
- 存储中出现未知值时不报错，按“最新在前”处理。

## 测试与验收

- 单元测试覆盖默认值、未知值回退、最新在前、最早在前和不修改输入数组。
- 侧栏契约测试确认排序下拉框存在，两个选项文案和存储键可用。
- 完整测试与构建必须通过。
- Edge 实机验收覆盖：默认倒序、切换后即时重排、关闭并重开侧栏后保持选择、新建文字或语音笔记出现在预期位置、ZIP 导出顺序仍为正序。
