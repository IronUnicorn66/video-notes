# 侧栏整体缩放设计

## 目标

为 Edge 扩展右侧栏增加整体缩放。用户在侧栏内按住 Ctrl 或 Command 滚动鼠标滚轮时，可放大或缩小标题、输入区、笔记列表、按钮、图片和设置区。普通滚轮继续滚动页面。

## 已确认交互

- 默认缩放比例为 100%。
- 缩放范围为 75%～200%。
- 每次滚轮事件调整 10%，到达边界时停在 75% 或 200%。
- Ctrl + 滚轮与 Command + 滚轮均可触发。
- 每次调整后短暂显示“侧栏缩放 N%”。
- 缩放比例保存在 `chrome.storage.local`，关闭并重新打开侧栏后继续使用。
- 不增加常驻按钮或新的设置项。

## 方案比较

### 方案一：浏览器原生页面缩放

优点是行为与普通网页完全一致。扩展侧栏无法通过现有页面上下文稳定调用原生标签页缩放接口，且该接口针对活动标签页，不适合控制扩展侧栏。

### 方案二：基于根字号调整各组件

可用 CSS 变量控制文本。当前侧栏大量尺寸使用像素值，按钮、间距、图片和弹窗不会随根字号完整缩放，需要改动较多样式。

### 方案三：根节点 CSS 缩放

在侧栏文档根节点应用 Chromium 支持的 CSS `zoom`。它会统一调整现有界面元素，并让布局按缩放后的可用宽度重新计算。该项目只面向 Microsoft Edge，因此兼容范围明确。采用此方案。

## 结构

新增独立的侧栏缩放模块，负责：

- 校验并限制缩放比例；
- 根据滚轮方向计算下一档比例；
- 只处理带 Ctrl 或 Command 的滚轮事件；
- 应用比例、写入本地存储并触发提示；
- 初始化时恢复已保存比例。

`sidepanel.js` 负责提供浏览器环境依赖：监听窗口滚轮、设置文档根节点缩放、调用现有提示组件，并在存储变化时同步比例。现有笔记编辑、滚动和历史操作逻辑保持不变。

## 数据流

1. 侧栏启动时读取 `sidepanelZoom`，无有效值时使用 100%。
2. 缩放模块将比例应用到文档根节点。
3. 用户按住 Ctrl 或 Command 滚动时，模块阻止该次滚轮的默认缩放行为。
4. 模块根据方向调整 10%，限制在 75%～200%。
5. 新比例立即应用、保存并通过现有提示显示。
6. `chrome.storage.onChanged` 收到其他侧栏实例的变化时同步显示比例，不重复提示。

## 异常与边界

- 缺失、非数字或非有限的存储值恢复为 100%。
- 超出范围的存储值限制到最近边界。
- `deltaY` 为零或没有修饰键的滚轮事件保持原行为。
- 已在边界继续向外滚动时阻止浏览器默认缩放，但不重复保存或提示。
- 存储写入沿用扩展现有本地存储调用方式，不改变笔记数据。

## 验证

自动化测试覆盖比例校验、上下限、滚轮方向、修饰键判断、边界行为、持久化与初始化恢复。完整测试套件和扩展构建必须通过。随后在真实侧栏中检查整体视觉缩放、普通滚动、提示显示及重新打开后的比例恢复。
