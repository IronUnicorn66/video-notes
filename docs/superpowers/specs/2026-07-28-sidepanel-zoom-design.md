# 侧栏缩放设计

## 目标

为视频笔记侧栏增加类似浏览器页面缩放的交互，缓解当前笔记正文和字幕字号偏小的问题。缩放覆盖标题、输入区、笔记时间线、按钮、图片和设置区，并在侧栏关闭后保留用户选择。

## 交互

- 用户按住 `Ctrl` 或 `Command` 并滚动鼠标滚轮时调整侧栏缩放比例。
- 向上滚动放大，向下滚动缩小；普通滚轮继续负责页面滚动。
- 缩放范围为 75%～200%，每次变化 10%，默认值为 100%。
- 比例变化后复用现有提示条显示“侧栏缩放 130%”一类反馈。
- 达到上限或下限后继续滚动时保持边界值，不重复保存或显示提示。
- 不增加常驻缩放控件。

## 实现边界

新增一个独立的侧栏缩放模块，负责比例校验、步进计算、滚轮事件判断和存储协调。侧栏入口只负责提供页面根元素、浏览器本地存储和提示回调。

页面通过 CSS `zoom` 缩放整个应用外观和布局。该扩展仅面向 Chromium 内核的 Microsoft Edge，CSS `zoom` 与目标运行环境匹配。现有响应式换行和纵向滚动继续处理放大后的可用空间变化。

缩放比例保存到 `chrome.storage.local`。侧栏初始化时读取该值并立即应用；缺失、非数字或超出范围的值统一校正到有效范围。一次滚轮动作只在比例实际变化时写入存储。

## 测试与验收

- 单元测试覆盖默认值、非法存储值、上下边界和 10% 步进。
- 交互测试确认仅 `Ctrl/Command + 滚轮` 会阻止默认滚动并触发缩放，普通滚轮保持原行为。
- 交互测试确认比例实际变化时应用 CSS、保存数值并显示反馈，边界处不重复执行副作用。
- 运行完整自动化测试与构建。
- 在 Edge 中打开扩展侧栏，验证放大、缩小、普通滚动、比例提示和关闭后重新打开的状态恢复。

## 非目标

- 不改变任何单独文本元素的基础字号。
- 不增加键盘加减号、重置快捷键或常驻按钮。
- 不同步到浏览器账户或其他设备。
