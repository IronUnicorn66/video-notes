# 视频笔记：多模型、笔记资产展示与课程专属侧栏设计

- 日期：2026-07-25
- 状态：用户已批准推荐方案
- 目标环境：桌面 Microsoft Edge 150、Apple Silicon、16 GB 内存

## 1. 目标

本次迭代同时解决三个已确认问题：

1. 用户可下载并切换三种本地 Whisper 模型，对同一段录音重复转写并比较结果。
2. 侧栏时间线显示文字和语音笔记的播放器截图；语音笔记同时提供原始录音播放器。
3. 侧栏只在受支持的课程标签中启用。课程标签之间切换时自动切换会话，普通标签隐藏侧栏。

## 2. 已确认的产品决策

- 提供 `base-q5_1`、`small-q5_1`、`medium-q5_0` 三种多语言量化模型。
- 下载过的模型全部保留，切回已缓存模型时不重复下载。
- 模型下载由用户明确触发，不因选择下拉项自动下载大文件。
- `medium-q5_0` 标注为实验性；初始化或转写失败不会删除模型，也不会阻止用户切回其他模型。
- 每条笔记默认显示截图缩略图，点击后在侧栏内放大。
- 每条语音笔记显示原始录音播放器。
- 语音笔记支持“用当前模型重新转写”，并保留历次模型结果。
- 课程 A 切到课程 B 时自动显示 B 的会话；切到普通网页时隐藏；返回 A 时恢复 A 的会话。

## 3. 不在本次范围

- 不并行加载或并行运行多个 Whisper 模型。
- 不提供“一次自动跑完三个模型”的批量按钮。
- 不删除已经缓存的模型，也不新增模型清理界面。
- 不从远程服务转写或上传录音。
- 不修改截图采集范围、WebP 质量和 Markdown ZIP 资产目录结构。
- 不增加 YouTube、哔哩哔哩之外的网站。

## 4. 模型目录与校验

三个模型固定到同一 Hugging Face 仓库修订 `98aa99a0a9db05ae2342309f5096248665f7cba3`：

| 模型 ID | 文件 | 精确大小 | 界面体积 | SHA-256 | 定位 |
| --- | --- | ---: | ---: | --- | --- |
| `base-q5_1` | `ggml-base-q5_1.bin` | 59,707,625 字节 | 57 MiB | `422f1ae452ade6f30a004d7e5c6a43195e4433bc370bf23fac9cc591f01a8898` | 默认 |
| `small-q5_1` | `ggml-small-q5_1.bin` | 190,085,487 字节 | 181 MiB | `ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb` | 更高准确率 |
| `medium-q5_0` | `ggml-medium-q5_0.bin` | 539,212,467 字节 | 514 MiB | `19fea4b380c3a618ec4723c3eef2eb785ffba0d0538cf43f8f235e7b3b34220f` | 实验性，可能较慢 |

模型元数据由 `WHISPER_MODELS` 目录统一提供；`base-q5_1` 保持默认值，以兼容已有安装状态。每个模型使用自己的正式缓存键和分块缓存键。下载完成后校验精确字节数和 SHA-256，校验失败只清除该模型的分块和错误正式缓存。

三个模型共用现有模型主机可选权限。每次下载前按用户手势申请权限，下载完成后撤销。远程内容仍只有静态模型权重。

## 5. 模型选择与运行状态

侧栏“本地 Whisper”设置改为以下结构：

- 模型下拉框：显示名称、体积、是否已缓存。
- 状态文字：显示当前选中模型、下载进度、当前转写模型或错误。
- 主按钮：根据状态显示“下载并切换”“切换”“下载中”“当前模型”或“重试”。

持久状态增加：

- `whisperSelectedModel`：用户当前选择且用于下一次转写的模型 ID。
- `whisperDownloadModel`：当前下载任务的模型 ID。
- `whisperDownloadedBytes`：当前模型已完成的字节数。

隐藏页在 `GET_PROCESSING_STATE` 中返回运行时 `loadedModelId`，表示当前 WASM 转写器加载的模型。该值不持久化；隐藏页销毁后由下一次转写按 `whisperSelectedModel` 重建。

已有 `whisperModel` 在迁移时映射到 `whisperSelectedModel`，随后停止写入。已有 `base-q5_1` 缓存继续有效。

切换规则：

1. 录音、下载或转写期间禁用切换和重新转写。
2. 选择未缓存模型时，只更新待选 UI；点击“下载并切换”后执行下载。
3. 选择已缓存模型并点击“切换”时，调用当前 `FileTranscriber.destroy()`，清除实例和初始化 Promise，然后更新选中模型。
4. 下一次转写按需初始化所选模型。同一时间内只保留一个转写实例，控制 WASM 内存占用。
5. `medium-q5_0` 初始化失败时状态进入 `error`，错误文字保留模型名称；其他已缓存模型仍可切换。

每个排队的转写任务在入队时固定 `modelId`，避免排队期间切换模型后使用到错误权重。

## 6. 重复转写与笔记数据

`NoteEntry` 增加两个可选字段：

- `transcriptionModelId`：当前展示转写所用模型。
- `transcriptionRuns`：按时间追加的转写记录，每项包含 `modelId`、`text`、`createdAt` 和 `source`；`source` 为 `automatic` 或 `manual`。

兼容规则：旧笔记缺少这些字段时按空数组处理，不升级 IndexedDB 结构版本。

首次录音完成后的自动转写和手动重新转写都走同一个串行队列。成功后先追加 `transcriptionRuns`，再按用户编辑状态应用文本：

- `userEditVersion === 0`：最新结果更新正文，并记录 `transcriptionModelId`。
- 用户已经编辑：正文保持不变，最新结果写入现有候选字段，同时保留完整历史。

重新转写按钮只在以下条件全部满足时启用：原始录音存在、当前模型已缓存、没有录音/下载/转写任务。点击后立刻显示目标模型和排队状态。

时间线增加“转写对比”折叠区，按模型和时间展示全部结果。Markdown 导出在个人正文之后增加同样的折叠区，确保对比结果不会因导出丢失。

## 7. 截图与录音在侧栏中的展示

当前截图缺失的界面原因已经确认：后台会采集并把 Blob 保存到 IndexedDB，导出也会读取资产；侧栏 `renderNotes()` 只渲染正文、时点、类型和告警，没有读取 `screenshotKey` 或 `audioKey`。

侧栏直接使用 `VideoNotesRepository` 读取同一扩展 IndexedDB，避免通过 Chrome 消息传输 Blob。展示流程如下：

1. 先同步渲染笔记文字骨架。
2. 对带 `screenshotKey` 的笔记异步读取 Blob，创建对象 URL，并渲染 `loading="lazy"` 的缩略图。
3. 点击缩略图打开侧栏内的图片查看层；点击遮罩、关闭按钮或按 Esc 关闭。
4. 对带 `audioKey` 的语音笔记读取 Blob，创建带 controls、`preload="metadata"` 的音频播放器。
5. 每次会话刷新、切换课程或侧栏卸载时撤销上一批对象 URL。

资产键存在但 Blob 缺失时，在对应卡片显示“截图资产缺失”或“录音资产缺失”。已有截图采集失败告警继续显示，不制造空白占位图。

## 8. 按课程标签启用侧栏

Manifest 继续声明本地 `default_path`，后台为每个标签设置覆盖选项：

- `parseVideoContext(tab.url)` 成功：调用 `sidePanel.setOptions({ tabId, path: "sidepanel.html", enabled: true })`。
- 解析失败或 URL 不可读：调用 `sidePanel.setOptions({ tabId, enabled: false })`。

后台在以下时机同步配置：

- 安装和浏览器启动时扫描现有标签。
- `tabs.onUpdated` 收到 URL 或加载状态变化时。
- `tabs.onActivated` 切换标签时重新确认当前标签选项。
- 内容脚本发出 `CONTEXT_CHANGED` 时，处理 YouTube 单页跳转和哔哩哔哩分 P。

使用 tab-specific side panel 后，每个课程标签拥有自己的侧栏实例。课程 A 与 B 之间切换时，Edge 自动切换对应实例；普通标签的扩展侧栏隐藏；返回 A 时恢复 A 的输入和时间线。侧栏刷新仍以当前标签的稳定 session ID 读取数据，防止跨课程串笔记。

## 9. 消息接口调整

新增或调整后台消息：

- `GET_WHISPER_STATUS`：返回模型目录、所选模型、缓存集合、活动模型、下载进度和全局任务状态。
- `SELECT_WHISPER_MODEL`：只接受目录中的模型 ID；已缓存时完成切换，未缓存时返回需要下载。
- `DOWNLOAD_WHISPER_MODEL`：携带模型 ID，下载、校验、缓存并选中。
- `RETRANSCRIBE_NOTE`：携带笔记 ID，使用当前选中模型加入串行队列。
- `TRANSCRIBE_NOTE`：内部调用增加固定的模型 ID。

所有模型 ID 在后台和隐藏页再次校验，页面消息不能注入任意下载 URL。

## 10. 错误处理

- 模型下载中断：保留该模型已校验长度的分块，重试时续传。
- 模型校验失败：清理该模型分块，显示模型名称和校验错误。
- 模型初始化失败：销毁不完整实例，允许切换其他缓存模型。
- 重新转写失败：保留旧正文和历史记录，在笔记上增加一次模型明确的告警。
- 截图或录音读取失败：只影响对应资产展示，正文、时点和导出入口继续可用。
- 标签切换期间有草稿或录音：沿用现有 pagehide/cancel 流程释放播放和麦克风租约；已保存笔记不受影响。
- `sidePanel.setOptions()` 失败：记录后台警告，不修改笔记或录音状态。

## 11. 测试与验收

### 自动测试

- 模型目录：三个 ID、精确大小、SHA-256、固定修订和非法 ID 拒绝。
- 模型缓存：按模型隔离、分块续传、缓存命中、校验失败只清理目标模型。
- 模型切换：销毁旧实例、缓存模型免下载、任务期间锁定、排队任务固定模型。
- 重复转写：自动与手动来源、未编辑正文更新、已编辑正文保护、历史追加和 Markdown 输出。
- 资产展示：截图和音频 Blob 读取、缺失告警、对象 URL 创建与撤销、图片查看层关闭。
- 侧栏范围：YouTube/Bilibili 启用，普通标签禁用，A/B 课程切换，站内跳转和分 P 更新。
- 回归：录音、截图、播放租约、网课声伴协作和 ZIP 相对链接保持通过。

### Edge 150 实机验收

1. 分别下载三个模型，确认缓存保留并能离线切换。
2. 用同一段原始录音依次重新转写三个模型，在侧栏和 Markdown 中看到三份带模型名结果。
3. 验证 medium 初始化失败时仍能切回 base 或 small，麦克风和播放租约没有残留。
4. 创建一条文字笔记和一条语音笔记，二者均显示截图；语音笔记能播放原始录音。
5. 点击截图放大并用 Esc 关闭；连续切换课程后没有显示旧课程图片。
6. 课程 A、普通网页、课程 B、课程 A 依次切换，观察侧栏隐藏、切换会话和恢复。
7. 导出 ZIP，确认 Markdown、截图、音频和转写对比记录都可用。
