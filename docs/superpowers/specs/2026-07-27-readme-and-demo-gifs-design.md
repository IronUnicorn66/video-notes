## GIF 录制方案

文件位置：

- `docs/assets/text-note-demo.gif`
- `docs/assets/voice-note-demo.gif`

录制使用当前 Microsoft Edge 中加载的真实插件和受支持的公开 YouTube 课程页。演示切换到一个独立视频会话，避免改动现有课程的笔记列表。

文字 GIF 流程：

1. 侧栏已打开且视频正在播放。
2. 点击快速标记输入框，视频进入暂停状态。
3. 输入“这里值得回看：模型从数据中学习表示”。
4. 按 `Esc` 取消临时标记，视频恢复播放。

语音 GIF 流程：

1. 视频正在播放，侧栏显示“按住说话”按钮。
2. 按住按钮约两秒，显示录音计时状态。
3. 松开按钮，视频恢复播放。
4. 侧栏出现带原始录音的语音标记。

语音演示在安静环境中录制，不包含个人谈话。演示产生的语音标记保存在独立视频会话中。

## 隐私与画面处理

- GIF 只保留视频内容和插件侧栏。
- 裁掉垂直标签栏、浏览器账号头像、地址栏、其他扩展和桌面内容。
- 不展示现有课程笔记、历史标签页、邮箱、账号名称或本地文件路径。

## 文件规格

- 宽度不超过 1000 像素。
- 帧率约 10–12 FPS。
- 每段时长约 8–12 秒。
- 使用独立调色板压缩，单个文件目标不超过 8 MiB。
- README 使用仓库内相对路径引用。
