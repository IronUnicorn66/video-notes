# 视频笔记：可配置前置字幕块设计

- 日期：2026-07-26
- 状态：用户已批准固定时长方案
- 目标环境：桌面 Microsoft Edge 150

## 1. 背景与问题定位

当前实现已经每 400 毫秒读取 YouTube 和哔哩哔哩播放器中可见的字幕，把标记前 20 秒、最多 500 字的内容保存到笔记 `subtitleContext`，并在 Markdown 导出中生成“前置字幕”。

从首个实现提交开始，侧栏 `renderNotes()` 没有渲染 `subtitleContext`，后台也没有更新该字段的消息。因此用户在侧栏中看不到已经采集的字幕，也不能继续编辑整理；只有导出后才可能看到字幕。

## 2. 目标

1. 在每张已保存的笔记卡片中提供独立的“前置字幕”块。
2. 用户可以独立编辑和保存字幕，不影响个人正文及语音转写保护。
3. 用户可以关闭字幕采集与字幕块展示。
4. 用户可以从 5、10、20、30 秒四个固定范围中选择采集窗口。
5. 已有安装和已有笔记无须迁移 IndexedDB。

## 3. 已确认的产品决策

- 字幕设置默认开启，默认读取标记前 20 秒。
- 读取范围使用 5、10、20、30 秒四个固定选项。
- 关闭设置后停止采集新字幕、清空当前页面尚未保存的字幕缓冲，并隐藏笔记卡片中的字幕块。
- 关闭设置不会删除已有笔记的 `subtitleContext`；重新开启后恢复展示。
- 本次继续读取播放器已经渲染的字幕，不主动开启播放器字幕，也不接入站点字幕接口。
- 字幕保持为独立字段，不自动合并到个人正文。

## 4. 不在本次范围

- 不读取播放器关闭时的字幕轨道。
- 不调用 YouTube 或哔哩哔哩的字幕接口。
- 不提供任意整数、自定义时长或超过 30 秒的范围。
- 不删除历史字幕。
- 不改变正文、语音转写、截图、录音和 ZIP 资产目录的现有行为。

## 5. 设置与兼容

在 `chrome.storage.local` 中增加两个设置：

- `subtitleEnabled`：布尔值，缺失或非法时使用 `true`。
- `subtitleWindowSeconds`：整数，只接受 5、10、20、30，缺失或非法时使用 `20`。

公共设置模块负责默认值和合法值归一化，内容脚本与侧栏共用同一规则。已有用户没有这两个键，会自然采用“开启、20 秒”，无需显式迁移。

侧栏现有“权限、语音与快捷键”设置区增加“前置字幕”设置行：

- 复选框控制字幕采集和字幕块展示。
- 下拉框提供 5 秒、10 秒、20 秒、30 秒。
- 关闭复选框时下拉框禁用，但保留最后选择的时长。
- 设置变更立即写入本地存储，并更新当前侧栏。

## 6. 字幕采集数据流

内容脚本启动时读取字幕设置，并监听 `chrome.storage.onChanged`：

1. `subtitleEnabled` 为 `false` 时，定时采集直接返回。
2. 从开启切换为关闭时，立即清空 `SubtitleBuffer`，防止重新开启后混入关闭前的未保存内容。
3. `subtitleWindowSeconds` 改变后，下一条标记直接使用新范围；现有笔记保持不变。
4. 创建标记时，关闭状态写入空的 `subtitleContext`；开启状态调用 `SubtitleBuffer.before()` 并传入当前范围。

`SubtitleBuffer` 继续保留 60 秒内容，足以覆盖最大 30 秒选项。现有 500 字上限保持不变，避免字幕块和存储记录无限增长。

## 7. 独立字幕块与编辑

侧栏读取当前字幕设置后渲染时间线：

- 设置关闭时，所有笔记卡片隐藏字幕块。
- 设置开启且 `subtitleContext` 有内容时，默认展开并显示字幕。
- 设置开启但内容为空时，显示“未读取到字幕，请确认播放器已开启字幕”。
- 空字幕仍提供“编辑字幕”入口，允许用户手工补充。

字幕块带独立“编辑字幕”按钮。编辑交互沿用正文规则：

- 点击后进入就地编辑并聚焦。
- 失焦或按 `Cmd/Ctrl + Enter` 保存。
- 按 `Esc` 放弃本次修改。
- 允许保存空内容，保存后恢复空字幕提示。

后台增加 `UPDATE_NOTE_SUBTITLE` 消息，只更新目标笔记的 `subtitleContext` 和 `updatedAt`。该操作不增加 `userEditVersion`，避免字幕编辑阻止后续语音转写更新个人正文。

Markdown 导出继续读取 `subtitleContext`，因此导出内容会反映用户最后保存的字幕修订。空字幕继续省略“前置字幕”章节。

## 8. 刷新、错误与边界

- 字幕编辑期间收到会话刷新或录音完成消息时，沿用现有延迟刷新控制，先完成或取消编辑，再刷新时间线。
- 字幕保存失败时保留当前可见内容并显示侧栏提示，用户可以再次编辑保存。
- 设置保存失败时恢复界面中的上一有效值并显示提示。
- 页面切换视频、关闭字幕设置时清空采集缓冲，避免字幕跨视频或跨启用状态混入。
- 旧笔记缺少 `subtitleContext` 时按空字符串展示。
- 当前选择器没有读取到字幕时不制造笔记告警；字幕块中的空状态提供可操作说明。

## 9. 测试与验收

### 自动测试

- 设置归一化：默认开启、默认 20 秒、四个合法选项和非法值回退。
- 字幕缓冲：5、10、20、30 秒窗口分别只返回范围内内容。
- 关闭采集：关闭状态的新标记字幕为空，重新开启后不会带入关闭前缓冲。
- 后台更新：字幕更新只修改 `subtitleContext` 和 `updatedAt`，不增加 `userEditVersion`。
- 侧栏结构：包含字幕开关、固定时长下拉框、字幕块、空状态和字幕更新消息。
- Markdown：编辑后的字幕被导出，空字幕省略对应章节。
- 回归：现有 95 项测试、构建和静态权限检查继续通过。

### Edge 150 实机验收

1. 首次加载确认字幕默认开启且范围为 20 秒。
2. 在 YouTube 和哔哩哔哩分别开启播放器字幕，播放超过 20 秒后创建标记，确认卡片显示标记前字幕。
3. 依次选择 5、10、20、30 秒并创建标记，确认新标记使用对应范围。
4. 编辑字幕后失焦保存，刷新侧栏并导出 ZIP，确认侧栏和 Markdown 保留修改。
5. 按 `Esc` 取消一次字幕编辑，确认原内容保持不变。
6. 关闭前置字幕后创建标记，确认停止采集且所有字幕块隐藏；重新开启后历史字幕重新出现。
7. 播放器未开启字幕时创建标记，确认显示空字幕提示，并可手工输入字幕。
