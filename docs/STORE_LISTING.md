# Edge 商店发布文案

## 简短说明

在 YouTube 和哔哩哔哩课程中用文字或按住说话快速标记，导出带截图、字幕、原始录音和时点链接的 Markdown 笔记。

## 权限披露

插件只在用户打开的 YouTube 和哔哩哔哩视频页读取播放器状态、当前已渲染字幕与可见播放器截图。麦克风只在用户按住说话期间启用。笔记、截图、字幕、录音和转写均留在浏览器本机。

首次启用本地语音时会下载 59,707,625 字节的 `base-q5_1` 静态模型权重，并按固定 SHA-256 校验。缓存完成后会撤销模型站点权限。安装包内包含全部 JavaScript、Worker 和 WASM，不加载远程可执行代码。

## 发布前替换项

- 把视频笔记和网课声伴的互信 ID 更新为两个 Edge 商店正式 ID。
- 如果审核拒绝运行时权重下载，使用构建脚本内置同一份已校验模型。
- 附上真实课程验收结果和 12 条本地转写性能表，不包含录音原文件。
