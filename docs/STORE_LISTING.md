# Edge 商店发布文案

## 简短说明

在 YouTube 和哔哩哔哩普通视频页中用文字或按住说话快速标记，导出带截图、字幕、原始录音和时点链接的 Markdown 笔记。

## 权限披露

插件只在用户打开的 YouTube 和哔哩哔哩视频页读取播放器状态、当前已渲染字幕与可见播放器截图。麦克风只在用户按住说话期间启用。笔记、截图、字幕、录音和转写均留在浏览器本机。

Edge 的可见页面截图接口要求 `<all_urls>` 或一次临时 `activeTab` 授权。插件把 `<all_urls>` 声明为可选权限，仅在用户点击“启用播放器截图”时请求；内容脚本仍只匹配 YouTube 和哔哩哔哩视频页。侧栏的麦克风授权按钮会打开一个扩展内部页面，只有用户在该页再次点击后才会触发 Edge 麦克风权限提示。

本地语音可下载三种固定模型：Base · 57 MiB（`ggml-base-q5_1.bin`，59,707,625 字节）、Small · 181 MiB（`ggml-small-q5_1.bin`，190,085,487 字节）、Medium · 514 MiB（`ggml-medium-q5_0.bin`，539,212,467 字节）。它们从 Hugging Face `ggerganov/whisper.cpp` 的固定 revision `98aa99a0a9db05ae2342309f5096248665f7cba3` 下载，并按固定 SHA-256 校验。Base 用于日常转写，Small 和 Medium 用于需要更大模型的场景；Medium 需要更多内存和时间。缓存完成后会撤销模型站点权限。安装包内包含全部 JavaScript、Worker 和 WASM，远程下载内容只有静态权重，不加载远程可执行代码。

已下载模型会全部保留；当前版本需通过 Edge 扩展管理页清除本扩展数据才能统一释放空间。重复转写会保留每条模型结果，也不会覆盖用户编辑的个人正文。时间线可查看截图，语音笔记可播放原始录音。

每个视频会话会持久保存最近 50 次笔记操作。文字和语音的时间点新增、正文编辑、字幕编辑、删除与清空均可撤销或重做；新建视频会话不进入撤销历史。删除和清空会先请求确认，删除的笔记采用软删除，截图和录音会在历史不再引用后自动最终回收。

## 发布前替换项

- 把视频笔记和网课声伴的互信 ID 更新为两个 Edge 商店正式 ID。
- 如果审核拒绝运行时权重下载，使用构建脚本内置同一份已校验模型。
- 附上真实课程验收结果和 12 条本地转写性能表，不包含录音原文件。
