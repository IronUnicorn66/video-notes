视频笔记隐私政策

生效日期：2026 年 9 月 1 日

概述

视频笔记用于在 YouTube 和哔哩哔哩课程中记录带时点的个人笔记，并按用户选择附带播放器截图、已经渲染的字幕、原始录音和本地语音转写。本政策说明扩展处理的信息、用途、权限、存储和删除方式。

处理的信息

  • 当前视频地址、标题、站点、视频标识、分 P 和播放时点。
  • 用户输入的笔记正文、字幕修订和撤销/反撤销历史。
  • 当前页面已经渲染的原生字幕或沉浸式翻译双语字幕，以及已读取的 YouTube 完整字幕和用户完成的本地全文译文。
  • 用户主动启用播放器截图后截取的可见播放器画面。
  • 用户按住说话期间的麦克风录音与本地 Whisper 转写结果。
  • 快捷键、字幕时长、侧栏整体缩放比例、完整字幕合并条数、字号和原文/译文显示偏好、时间线顺序、权限和模型状态设置。
  • 浏览器本地翻译所需的字幕语言、用户选择的目标语言代码、所选语言包和浏览器语言包状态。

扩展不会在后台建立浏览历史，也不会读取受支持视频页以外的网站内容来生成笔记。

完整 YouTube 字幕读取遇到平台限制时，扩展可能短暂切换播放器字幕开关以捕获播放器发起的原生字幕响应，并立即恢复原先状态。

存储与处理位置

笔记、字幕、截图、录音、转写结果、视频会话信息，以及按视频缓存的 YouTube 完整字幕和已完成全文译文，都保存在扩展自己的 IndexedDB。全文译文按目标语言与 5/10/20 合并档位分别保存。设置（包括侧栏整体缩放比例、浏览器可用语言代码、所选语言包和语言对状态）保存在扩展本机存储中，Whisper 模型权重保存在 Cache Storage。浏览器翻译语言包由 Edge 或 Chrome 分别管理。

扩展没有开发者服务器，不会把笔记、字幕、截图、录音、转写结果或视频访问记录上传给开发者。扩展不包含账户、广告或分析统计，也不会出售、出租或共享用户数据。

本地全文翻译

全文翻译只使用桌面 Edge 或 Chrome 内置的 Translator API。扩展先在本机参考中英文句号、问号、叹号、逗号等标点把完整字幕整理为段落，再以完整段落作为翻译输入。扩展从完整字幕轨道自动识别源语言；首版允许用户选择简体中文、英语、日语、韩语或西班牙语作为目标语言。读取完整字幕后，用户可以在设置中提前下载当前源语言到目标语言的语言包并查看进度；下载前不显示大小，下载完成后显示约 200 MiB 的预估占用。实际占用由浏览器版本和语言包版本决定。

翻译会话创建在侧栏文档中，字幕和译文由浏览器在本机处理，不会发送给扩展开发者或第三方翻译服务。当前目标语言和合并档位的全文翻译完成后，扩展会把译文写入本地字幕缓存，便于再次打开同一视频时恢复；部分完成的全文译文不会写入持久缓存。浏览器可能在首次下载某个语言对时联网获取语言包；下载请求不包含字幕、笔记、截图、录音或转写内容。语言包下载完成后可断网翻译。Edge 与 Chrome 分别管理语言包，扩展不下载、打包或跨浏览器同步翻译模型。

Whisper 模型下载

用户主动选择本地语音模型后，扩展会从 Hugging Face 的 ggerganov/whisper.cpp 固定 revision 下载 Base、Small 或 Medium 静态权重。下载后会校验固定文件大小和 SHA-256，校验通过才会写入本地缓存。下载完成后，扩展撤销模型主机权限。

远程响应只包含静态模型数据。JavaScript、Worker 和 WASM 均由扩展安装包提供，转写在本机运行。

模型下载请求会直接连接 Hugging Face、其 CDN 或 XetHub。和普通 HTTPS 请求一样，这些服务会收到完成下载所需的连接元数据，例如 IP 地址、User-Agent、请求时间和模型文件地址；请求不会包含笔记、字幕、截图、录音或转写内容。扩展和开发者不读取或保存这些连接元数据。第三方如何处理连接元数据请参阅 Hugging Face 隐私政策。

权限用途

  • 存储：保存设置、权限、模型状态和用户记录。
  • 当前标签页与脚本：在受支持的课程页读取视频时点和字幕；完整 YouTube 字幕读取受限时，可能短暂切换播放器字幕后恢复，以捕获其原生字幕响应，并在连接失败时恢复本地内容脚本。
  • 侧栏：提供笔记输入、设置和时间线。
  • 隐藏页：在授权后维持录音、本地转写和导出文件生成。
  • 下载：保存用户主动导出的 ZIP。
  • 可选截图权限：只在用户启用播放器截图并同意浏览器提示后授予；本地浏览器翻译不使用该权限。
  • 可选模型主机权限：只用于用户主动发起的固定 Whisper 权重下载。

麦克风与播放器截图

麦克风只在用户按住右 Option/Alt 或侧栏“按住说话”按钮期间录音。窗口失焦、页面隐藏、侧栏关闭或达到 60 秒上限时会停止录音。

播放器截图默认关闭。用户必须在侧栏中单独启用并接受浏览器的可选权限提示。关闭权限后，新笔记不再保存截图。

保留与删除

扩展会保留视频会话、完整字幕缓存、已完成全文译文和已下载的 Whisper 模型，便于再次打开同一视频时继续记录。删除单条笔记或清空时间线只删除对应笔记，不删除字幕缓存；“重试”会用重新采集的字幕更新当前视频缓存。用户可以在 Edge/Chrome 扩展管理页清除本扩展数据，卸载扩展也会由浏览器清除扩展存储。浏览器翻译语言包由浏览器自身管理。

导出 ZIP 不会删除浏览器中的会话。已经保存到下载目录的 ZIP 由用户自行管理。

政策更新

如果扩展的数据处理方式、权限或联网范围发生变化，本页面会在新版本发布前更新，并修改顶部生效日期。
