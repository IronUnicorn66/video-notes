怎样使用

四步，把一段课程变成能继续使用的材料

字幕、译文与笔记一直留在视频旁。看懂、记录、回看和导出不必来回切换窗口。

01

安装到 Edge / Chrome

优先从 Edge 商店安装；在 Chrome 使用或提前试用时，可下载 ZIP 并加载解压后的目录。

02

在课程旁打开侧栏

进入 YouTube 或哔哩哔哩课程，点击工具栏中的“视频笔记”；YouTube 有可用字幕轨时还能读取完整字幕。

03

读原文，也读译文

自动识别字幕语言，用浏览器本地语言包翻译完整段落，并切换原文、译文或双语对照。

04

记下重点再导出

输入时视频暂停、保存后续播；笔记可带时点、字幕、译文、截图或语音，最后导出 Markdown ZIP。

浏览器本地翻译

完整字幕可以直接双语对照

扩展使用 Edge / Chrome 内置 Translator API，字幕内容不会发送给开发者或第三方翻译服务。源语言自动识别，目标语言可选简体中文、英语、日语、韩语或西班牙语。

  • 下载后可离线提前下载当前语言对，断网后仍能翻译。
  • 三种阅读方式只看原文、只看译文，或上下双语对照。
  • 回到上次位置字幕、已完成译文和阅读进度按视频缓存在本机。

安装

从 Edge 商店安装，或手动加载到 Edge / Chrome

Edge 商店已公开上架；1.0.34 更新通过审核后会自动更新。需要在 Chrome 使用或提前试用时，可下载同一份 GitHub Release 发布包。

打开 Edge 商店 下载 1.0.34 ZIP
  1. 1

    下载并解压 ZIP保留到一个固定目录

  2. 2

    打开浏览器扩展管理页Edge 或 Chrome 开启“开发人员模式”

  3. 3

    加载解压缩的扩展选择含 manifest.json 的目录

当前功能

从阅读到记录，再到整理，一条流程完成

≡

完整字幕跟着进度读

YouTube 完整字幕可按完整句合并阅读、点击时间跳转、定位当前播放段落并调整字号；字幕列表和阅读位置会在本机恢复。

⌁

每条笔记保留完整来处

时点、按完整句整理的标记前字幕、匹配的本地译文、播放器截图和原始语音都能跟着笔记保存；语音还可用 Whisper 在本机转写。

↶

时间线可改，也能撤回

正序或倒序查看，编辑、删除、清空、撤销与反撤销；调整侧栏和笔记字号后，一键导出 Markdown、图片与原始录音。

支持 YouTube 与哔哩哔哩课程视频

YouTube 普通视频页支持完整字幕阅读与本地全文翻译；哔哩哔哩支持 BV 视频与分 P，优先读取播放器已显示的原生或双语字幕，并尽力读取当前分 P 的原生字幕轨。部分新版 B 站页面仍可能无法取得原生轨回退。
