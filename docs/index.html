使用方法

从“这里很重要”到一条完整笔记

不改变看课节奏，标记和上下文一起保存。

01

打开侧栏

进入 YouTube 或哔哩哔哩视频，点击工具栏中的“视频笔记”。

02

留下想法

点击输入框会暂停视频；输入后移开焦点，笔记自动保存并续播。

03

带走上下文

按需保存播放器截图、标记前字幕，或按住说话补充语音。

04

导出整理

一键导出 Markdown ZIP，在自己的笔记工具中继续编辑。

本地优先

你的课程记录，不需要经过另一个服务器。

笔记、字幕、截图、录音和转写结果都保存在扩展自己的浏览器存储中。模型权重来自固定来源，经过大小和 SHA-256 校验后缓存到本机。

安装测试版

下载 ZIP，在 Edge 中加载

Microsoft Edge Add-ons 首次审核期间，可以安装同一份 1.0.1 发布包进行体验。

下载视频笔记 1.0.1
  1. 下载并解压 ZIP保留到一个固定目录
  2. 打开 edge://extensions/开启“开发人员模式”
  3. 加载解压缩的扩展选择含 manifest.json 的目录
  4. 打开课程视频点击“视频笔记”工具栏图标
