怎样使用

四步，把视频重点变成可整理的笔记

侧栏一直留在视频旁。记录完成后接着播放，看完再统一整理。

01

安装到 Edge

下载测试版 ZIP，在扩展管理页加载解压后的目录。

02

打开视频侧栏

进入 YouTube 或哔哩哔哩课程，点击工具栏中的“视频笔记”。

03

看到重点就记

输入时视频暂停，保存后续播；按需带上字幕、截图或语音。

04

导出继续整理

一键导出 Markdown ZIP，在自己的笔记工具中继续编辑。

安装测试版

下载 ZIP，三步加载到 Edge

Microsoft Edge Add-ons 审核期间，可以先安装同一份 1.0.5 发布包。

下载视频笔记 1.0.5

  2. 2

  3. 3

能带来什么

看完一门课，带走一份能继续使用的材料

▶

跟得上课程节奏

输入时自动暂停，保存后接着播放。重点当场记下，观看节奏仍然连贯。

⌁

每条笔记都找得到来处

时点、标记前字幕、播放器截图和语音跟着笔记保存，回看时能快速恢复语境。

⇩

看完就能继续整理

导出 Markdown、图片和原始录音，在 Obsidian 等现有工具中继续组织；内容与转写留在浏览器本机。

支持 YouTube 与哔哩哔哩课程视频

支持 YouTube 普通视频页、哔哩哔哩 BV 视频页与分 P；字幕来自播放器已经显示的内容。
