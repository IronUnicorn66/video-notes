How it works

Four steps from a lesson to material you can keep using

Transcripts, translations, and notes stay beside the video, so reading, capturing, revisiting, and exporting do not require constant window switching.

01

Install it in Edge / Chrome

Install from Microsoft Edge Add-ons, or download the ZIP and load its extracted folder to use Chrome or try the update sooner.

02

Open it beside the lesson

Start a YouTube or Bilibili lesson and select Video Notes in the toolbar. YouTube transcripts appear when a compatible native track is available.

03

Read the source and translation

Detect the transcript language, translate complete paragraphs with a local browser language pack, and switch between source, translation, or both.

04

Capture, then export

Playback pauses while you type and resumes after saving. Notes can include time, subtitles, translation, a screenshot, or voice before export.

Local browser translation

Read the full transcript bilingually

Video Notes uses the built-in Edge / Chrome Translator API, so transcript content is not sent to the developer or a third-party translation service. It detects the source language and can target Simplified Chinese, English, Japanese, Korean, or Spanish.

  • Works offline after downloadPre-download the current language pair and keep translating without a connection.
  • Three reading modesShow only the source, only the translation, or a bilingual comparison.
  • Resume where you left offTranscripts, completed translations, and reading positions are cached locally per video.

Current features

One flow from reading to capture and organization

≡

Read the full transcript with playback

Group YouTube transcripts into complete sentences, jump by timestamp, locate the current passage, adjust text size, and restore your reading position locally.

⌁

Keep every note traceable

Save a timestamp, sentence-aware lead-in subtitles, matching local translation, player screenshot, and original voice with a note. Optional Whisper models transcribe voice locally.

↶

Edit the timeline and undo changes

Sort, edit, delete, clear, undo, and redo. Adjust the panel and note text size, then export Markdown, images, and original recordings in one ZIP.

Built for YouTube and Bilibili lessons

Standard YouTube videos support full-transcript reading and local translation. Bilibili BV videos and multi-part lessons use native or bilingual subtitles already shown by the player, with a best-effort native-track fallback that may still be unavailable on some newer pages.
