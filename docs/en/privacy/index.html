Privacy Policy

Video Notes privacy policy

Effective date: July 28, 2026

Overview

Video Notes creates timestamped personal notes while you watch YouTube and Bilibili lessons. At your request, a note can include a player screenshot, subtitles already rendered on the page, an original voice recording, and a local voice transcription. This policy explains what the extension processes, why it processes it, the permissions it uses, where information is stored, and how you can delete it.

Information the extension processes

  • The current video URL, title, site, video identifier, part number, and playback time.
  • Your note text, subtitle edits, and undo or redo history.
  • Native subtitles or bilingual Immersive Translate subtitles already rendered on the current page.
  • The visible player image when you explicitly enable player screenshots.
  • Microphone audio recorded while you hold the talk control, plus local Whisper transcription results.
  • Shortcut, subtitle window, timeline order, permission, language, and model settings.

The extension does not build a background browsing history or read unrelated website content to create notes.

Storage and processing location

Notes, subtitles, screenshots, recordings, transcriptions, and video session information are stored in the extension’s IndexedDB. Settings are stored in extension storage. Model weights are stored in Cache Storage. Personal content is processed on your device.

Video Notes has no developer-operated server. It does not upload your notes, subtitles, screenshots, recordings, transcriptions, or video visit history to the developer. It has no account system, advertising, or analytics, and it does not sell, rent, or share your data.

Whisper model downloads and connection metadata

When you choose a local voice model, the extension downloads pinned Base, Small, or Medium weights from the ggerganov/whisper.cpp repository on Hugging Face. It verifies the exact file size and SHA-256 before saving the model to local cache, then removes the model-host permission after the download completes.

Remote responses contain static model data only. JavaScript, Worker, and WASM code ship inside the extension package, and transcription runs locally.

Connection metadata: model downloads connect directly to Hugging Face, its CDN, or XetHub. Like any standard HTTPS request, these services receive the connection information needed to deliver the file, such as your IP address, User-Agent, request time, and model file URL. The request contains no note, subtitle, screenshot, recording, or transcription content. The extension and its developer do not read or retain this connection metadata. See the Hugging Face privacy policy for the third party’s practices.

Why each permission is used

  • Storage: saves settings, permission state, model state, and your records locally.
  • Active tab and scripting: reads video time and already-rendered subtitles on supported lesson pages, and restores the packaged content script when the connection is interrupted.
  • Side panel: provides note input, settings, and the timeline beside the video.
  • Offscreen document: maintains authorized recording, local transcription, and export generation.
  • Downloads: saves the ZIP you explicitly export.
  • Optional screenshot permission: is requested only when you enable player screenshots and accept the Edge prompt.
  • Optional model-host permission: is requested only for a model download you start.

Microphone and player screenshots

The microphone records only while you hold Right Option/Alt or the Hold to talk button. Recording stops if the window loses focus, the page becomes hidden, the side panel closes, or the 60-second limit is reached.

Player screenshots are disabled by default. You must enable them in the side panel and accept Edge’s optional permission prompt. After the permission is removed, new notes stop capturing screenshots.

Retention and how to delete your data

Video Notes retains video sessions and downloaded models so you can continue when you return to the same lesson. You can delete one note, clear every note for the current video, or clear the extension’s data from the Edge extension management page. Uninstalling the extension causes the browser to clear extension storage.

Exporting a ZIP does not delete the browser session. You control ZIP files after they are saved to your Downloads folder.

Policy updates

If the extension’s data processing, permissions, or network access changes, this page will be updated before the new version is released and the effective date above will change.

Contact

For general questions, use GitHub Issues. The repository and existing issues are public; a GitHub login is required to create a new issue. Report security concerns privately through a GitHub Security Advisory.
