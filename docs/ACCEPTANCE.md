## 三、笔记资产与侧栏（待用户手动验收）

- [ ] 首次加载确认前置字幕默认开启且范围为 20 秒。
- [ ] 在 YouTube 和哔哩哔哩分别开启播放器字幕，播放超过 20 秒后创建标记，确认卡片显示标记前字幕。
- [ ] 依次选择 5、10、20、30 秒并创建标记，确认新标记使用对应范围。
- [ ] 编辑字幕后失焦保存，刷新侧栏并导出 ZIP，确认侧栏和 Markdown 保留修改。
- [ ] 按 `Esc` 取消一次字幕编辑，确认原内容保持不变。
- [ ] 关闭前置字幕后创建标记，确认停止采集且所有字幕块隐藏；重新开启后历史字幕重新出现。
- [ ] 播放器未开启字幕时创建标记，确认显示空字幕提示，并可手工输入字幕。
- [ ] 在有原生字幕的 YouTube 视频中打开“完整字幕”，确认状态显示段数、覆盖起止时间和字幕语言；“合并条数”、5/10/20/30 四选一以及“翻译 / 重试”都保持在同一行，后两个按钮为紧凑宽度且文字不换行。默认选中 5；选择其他条数后立即重排，点击时间范围跳到该段第一条字幕均正常。
- [ ] 未填写翻译设置时点击“翻译”，确认展开并聚焦“全文翻译（OpenAI 兼容）”设置，且不发起网络请求；填写自己的 HTTPS API Base URL、API Key 和模型名并保存后，仅出现该 API 主机的可选权限提示。
- [ ] 使用自己的已授权 OpenAI 兼容 API 翻译一条带原生字幕的 YouTube 课程，确认显示批次进度、原文与简体中文译文上下对照；失败后保留已完成译文并可以“继续翻译”；关闭侧栏、切换视频或重新读取字幕后译文不保留。
- [ ] 在侧栏点击“启用播放器截图”并完成 Edge 可选权限授权，确认文字笔记和语音笔记都能保存当前可见播放器截图。
- [ ] 在独立扩展授权页完成麦克风授权后，按住右 Option/Alt 录制一条语音笔记；确认松开后保存原始录音并恢复视频播放。
- [ ] 创建一条文字笔记和一条语音笔记，确认侧栏均显示截图。
- [ ] 确认语音笔记可以播放保存的原始录音；点击缩略图可放大并关闭。
- [ ] 分别在 YouTube 和哔哩哔哩播放视频后点击快速标记输入框，确认视频暂停；输入正文后单击已暂停的播放器一次，确认笔记自动保存且视频立即续播，无需第二次点击。
- [ ] 保持受支持的视频页打开，重新加载扩展后不刷新视频页，直接打开侧栏；确认标题与快速标记输入框恢复，点击输入框可暂停视频并保存或取消标记。
- [ ] 保持侧栏打开，在 Edge 扩展菜单中关闭再开启当前视频网站的扩展总开关并按提示刷新；确认侧栏先显示中文权限指引，随后自动恢复标题与快速标记输入框，无需关闭侧栏。
- [ ] 依次切换课程 A、普通网页、课程 B、课程 A，确认侧栏依次显示 A、隐藏、显示 B、恢复 A。
- [ ] 确认侧栏只在 YouTube 普通视频页和哔哩哔哩普通 BV 视频页启用。
- [ ] 与网课声伴一起使用时，确认语音期间 A/B 都暂停，松开后按恢复资格恢复；文字输入保留现有 A/B 接力行为。
- [ ] 网课声伴处于“全部暂停”时结束语音，确认 A/B 不恢复；关闭或切换普通标签后确认视频与录音租约释放。

## 四、导出与异常路径（待用户手动验收）

- [ ] 导出 ZIP，检查 Markdown、`images/`、`audio/`、时点链接和相对路径。
- [ ] 模拟前置字幕开关和读取范围写入失败，确认控件恢复上一有效值并显示错误提示。
- [ ] 模拟字幕保存失败，确认未保存文本保持可见；再次点击“编辑字幕”后确认原输入仍在，并可重试保存成功。
- [ ] 在侧栏刷新请求尚未返回时开始编辑正文或字幕，确认迟到响应不会替换编辑区；保存或取消后确认时间线只刷新一次。
- [ ] 拒绝麦克风权限后，确认视频与录音租约均已释放。
- [ ] 断网后开始模型下载或转写，确认错误可见且视频与录音租约均已释放。
- [ ] 录音、下载或转写期间关闭课程标签，确认视频与录音租约均已释放。

## 五、笔记历史与删除（待用户手动验收）

- [ ] 创建文字笔记和语音笔记后，分别执行“撤销”和“反撤销”，确认时间点新增可撤销；新建视频会话不会被撤销移除。
- [ ] 编辑个人正文和前置字幕后，确认可通过 `Cmd/Ctrl + Z` 撤销，并通过 `Cmd/Ctrl + Shift + Z` 重做；执行新的编辑后确认重做失效。
- [ ] 连续执行超过 50 次可撤销操作，重启 Edge 后确认仅保留最近 50 次持久历史，并可继续撤销或重做。
- [ ] 删除单条笔记时确认出现确认框；取消后笔记仍在，确认后笔记从时间线隐藏并可撤销恢复。
- [ ] 点击“清空”时确认出现确认框；取消后会话不变，确认后全部笔记以一次原子操作清空并可一次撤销恢复。
- [ ] 删除包含截图和录音的笔记后撤销，确认资产仍可显示和播放；当历史不再引用该软删除笔记后，确认截图和录音资产被最终回收。
