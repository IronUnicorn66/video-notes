# Edge 150 实机验收清单（0.2.0）

此清单区分可自动执行的发布校验和需要在桌面 Edge 150 中完成的人工验收。人工项目由用户实际操作并记录结果，未执行前保持“待用户手动验收”。

## 一、发布自动校验

- [x] 已自动验证：`npm test` 通过（86 个测试）。
- [x] 已自动验证：`npm run build` 成功，`dist/manifest.json` 的版本为 `0.2.0`。
- [x] 已自动验证：`npm run package` 成功，生成 `artifacts/video-notes-edge-0.2.0.zip`。
- [x] 已自动验证：`unzip -t artifacts/video-notes-edge-0.2.0.zip` 通过；根目录包含 `manifest.json`、`sidepanel.html` 和 `offscreen.html`。
- [x] 已自动验证：发布 ZIP 不包含 `ggml-small-q5_1.bin` 或 `ggml-medium-q5_0.bin`。
- [x] 已自动验证：`git diff --check` 无空白错误。

## 二、模型下载与转写（待用户手动验收）

- [ ] 分别下载 Base · 57 MiB（59,707,625 字节）、Small · 181 MiB（190,085,487 字节）和 Medium · 514 MiB（539,212,467 字节）；确认它们都来自固定 Hugging Face revision `98aa99a0a9db05ae2342309f5096248665f7cba3`。
- [ ] 中断一次 Small 下载后继续下载，确认续传完成并通过校验。
- [ ] 重启 Edge 后确认三种模型仍显示为已下载。
- [ ] 使用同一条 3–15 秒中文及中英混合录音，分别以 Base、Small、Medium 重新转写；确认卡片和 Markdown 保留三条结果。
- [ ] 在编辑个人正文后重新转写，确认个人正文保持不变，新结果进入候选和历史。
- [ ] 下载、录音或转写进行时尝试切换模型，确认控件不可切换；确认同一时刻内存中只有一个 Whisper 实例。
- [ ] 在桌面 Edge 中使用 Medium，记录下载、加载和转写耗时及内存，确认机器可承受其较高资源消耗。

## 三、笔记资产与侧栏（待用户手动验收）

- [ ] 在侧栏点击“启用播放器截图”并完成 Edge 可选权限授权，确认文字笔记和语音笔记都能保存当前可见播放器截图。
- [ ] 在独立扩展授权页完成麦克风授权后，按住右 Option/Alt 录制一条语音笔记；确认松开后保存原始录音并恢复视频播放。
- [ ] 创建一条文字笔记和一条语音笔记，确认侧栏均显示截图。
- [ ] 确认语音笔记可以播放保存的原始录音；点击缩略图可放大并关闭。
- [ ] 依次切换课程 A、普通网页、课程 B、课程 A，确认侧栏依次显示 A、隐藏、显示 B、恢复 A。
- [ ] 确认侧栏只在 YouTube 普通视频页和哔哩哔哩普通 BV 视频页启用。
- [ ] 与网课声伴一起使用时，确认语音期间 A/B 都暂停，松开后按恢复资格恢复；文字输入保留现有 A/B 接力行为。
- [ ] 网课声伴处于“全部暂停”时结束语音，确认 A/B 不恢复；关闭或切换普通标签后确认视频与录音租约释放。

## 四、导出与异常路径（待用户手动验收）

- [ ] 导出 ZIP，检查 Markdown、`images/`、`audio/`、时点链接和相对路径。
- [ ] 拒绝麦克风权限后，确认视频与录音租约均已释放。
- [ ] 断网后开始模型下载或转写，确认错误可见且视频与录音租约均已释放。
- [ ] 录音、下载或转写期间关闭课程标签，确认视频与录音租约均已释放。

## 五、数据清理（待用户手动验收）

- [ ] 确认已下载模型没有删除入口，导出不会删除本地会话或模型。
- [ ] 在 Edge 扩展管理页清除本扩展数据，确认 Base、Small、Medium 缓存和本地笔记统一释放。
