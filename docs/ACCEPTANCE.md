# Edge 150 实机验收清单

## 一、安装和基础页面

- 从 `dist` 加载扩展后无 Manifest、CSP 或服务工作线程错误。
- 首次打开侧栏时权限区自动展开；截图可从侧栏完成授权，麦克风按钮会打开独立授权页，并在用户点击后显示 Edge 权限提示；成功后回到发起授权的课程标签。
- YouTube 普通视频页与哔哩哔哩 BV 视频页能打开侧边栏并显示正确标题。
- 站内切换视频和哔哩哔哩分 P 后，会话 ID 随页面变化；回到旧视频能看到旧标记。
- 依次切换课程 A、课程 B、普通网页，再返回课程 A：课程页侧栏可打开并显示各自会话；普通网页侧栏不可打开；返回 A 后恢复 A 的标记。

## 二、文字标记

- 输入框聚焦后视频暂停，标记时点与聚焦瞬间一致。
- 中文输入法组合期间不会误提交；普通 Enter 换行。
- 失焦且有内容时保存并续播；空内容取消；`Cmd/Ctrl + Enter` 保存；`Esc` 取消。
- 用户在暂停后手动控制视频时，插件不会擅自恢复。

## 三、语音标记

- 页面内按住右 Option/Alt 开始录音，松开后结束；输入控件内不会触发。
- 麦克风尚未授权时按右 Option/Alt，视频不进入暂停租约，并打开独立麦克风授权页。
- 按键到 A/B 静音不超过 200ms；首次授权后按键到录音就绪不超过 500ms；松键到视频恢复不超过 250ms。
- 窗口失焦、标签页切换、页面关闭、侧边栏关闭和 60 秒上限都能释放麦克风与播放租约。
- 快速松键后立刻再次按键不会串写两段录音；上一段保存完成后可开始下一段。
- 松键后先看到原始录音已保存，再发生后台转写；编辑正文后到达的转写只进入候选区。
- 第一条仍在转写时继续录制第二条，两条会依次完成；转写期间重启浏览器后，已保存的待办会继续处理。

## 四、Whisper 门槛

使用同一位真实说话人的 12 条 3–15 秒录音，至少包含 4 条中文、4 条中英混合、2 条数字或专有名词、2 条自然停顿。逐条记录参考文本、转写文本、录音长度、转写耗时和进程峰值内存。

通过条件：归一化编辑错误率中位数不高于 20%；15 秒样本的转写耗时 P95 不超过 8 秒；峰值内存不超过 750MB。

若 `base-q5_1` 只因性能失败，再用 `tiny-q5_1` 重复同一组样本。只有准确率和性能同时通过才修改默认模型。两个模型均失败时，把本地语音状态保留为错误，继续提供文字和原始录音。

## 五、网课声伴

- 语音期间 A/B 都暂停，无播放振荡；文字输入期间 B 按既有规则接力。
- 网课声伴处于“全部暂停”时，语音结束不会恢复 A/B。
- 心跳停止 90 秒后租约自动释放；伪造扩展 ID 和非 A 标签页请求被拒绝。
- 网课声伴缺失或版本不兼容时，视频笔记仍能录音并在时间线显示一次联动告警。

## 六、导出压力

- 一条 YouTube 和一条哔哩哔哩真实课程均完成观看、标记和 ZIP 导出。
- 至少 100 条混合文字/语音标记导出成功。
- Markdown 中个人内容位于字幕前；截图可打开；录音可播放；每个时点链接能跳到正确视频位置。
