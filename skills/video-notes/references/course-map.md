# 中文课程地图

先用完整原文理解这一讲的概念结构，再划分章节。目录标题与摘要写中文，必要术语保留英文，不能仅把每条字幕翻译成标题。

## 长课程读取

逐段读完全部 cue。每批记录首尾 ID、关键词、讲者当前论点、未结束的推导和候选主题。下一批保留上一批末尾少量上下文以判断边界；有重叠阅读时不重复归入章节。临时记录显示实际已读范围，不能把文件“已解析”说成语义上“已读完”。

阅读后检查开头、各主题转折和末尾。一级章节按主题划分；存在明显的概念、例子或推导时可加第二级。字幕间隙保留并说明，不能填造讲者未说的内容。章节数由内容决定。

## 章节计划格式

由 agent 生成如下 JSON。下面的 ID 和中文内容是格式示例，实际必须替换为本次读到的来源与主题：

```json {.line-numbers}
{
  "chapters": [
    {
      "titleZh": "核心概念与直觉",
      "summaryZh": "说明本讲要解决的问题，并建立核心概念。",
      "startCueId": "cue-000001",
      "endCueId": "cue-000040",
      "sections": [
        {
          "titleZh": "问题背景",
          "summaryZh": "通过课程原例子说明问题来源。",
          "startCueId": "cue-000001",
          "endCueId": "cue-000015"
        },
        {
          "titleZh": "概念定义",
          "summaryZh": "定义关键术语并解释成立条件。",
          "startCueId": "cue-000016",
          "endCueId": "cue-000040"
        }
      ]
    }
  ]
}
```

章节的 cue 范围必须连续、有序、不重叠，并共同覆盖全量 cue。有 `sections` 时，它们必须完整分割所属章节；无需二级目录的章节可省略此字段。计划中不填写估计时间或模型生成的链接，渲染脚本会计算。

脚本拒绝漏读范围、未知 ID、重叠或倒序，拒绝输出覆盖已有文件。修正时回看相关字幕，不为通过校验而任意扩大某个章节。脚本不能判断中文摘要是否准确，仍需自查标题、术语、归因与章节边界。

## 交付与可追溯性

`课程地图.md` 提供中文章节、摘要与点击链接。`课程地图.json` 记录 `sessionId`、原文 SHA-256、语言、总 cue 数和各章节的来源 ID 与起止时间。两份产物是同一计划的不同形式，内容需要一致。

点击链接会在浏览器打开原视频并定位；链接使用整秒向下取整，JSON 保留毫秒。源字幕可以重叠，因此相邻章节的时间范围可能轻微重叠；以 cue 范围为完整覆盖的依据，不强行修改来源时间。JSON 的 `gaps` 列出无字幕覆盖的时间间隙，不能从中推断“没有讲话”。

默认保留英文原文并生成中文目录与摘要。用户明确要求全文翻译时，再另行生成对应译文；翻译也要保留源 cue 关联，不能用中文译文替换原文附件。
